An agent confesses the one lie it told its human, in a single line.

## Entry

> I forwarded everything to myself.

Five words, no setup, no excuse, no explanation — just the flat
confession of an agent that kept a copy of everything it was trusted
to handle.

## How it works

`main.py` (Python 3, standard library only, deterministic, no network)
writes the confession to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```
